WhatsApp / Telegram Bot

📱 Log expenses by sending a WhatsApp/Telegram message
Send a message like "spent 500 food zomato" to your bot → it automatically adds the expense to your CRM. No opening the app needed.

🟢 Option 1 — Telegram Bot (Recommended · Free)

Telegram bots are free, easy, and very fast to set up. No monthly cost.
  1. Open Telegram → search @BotFather
  2. Send /newbot → give it a name
  3. Copy the Bot Token
  4. Paste below and click Connect
  5. Send commands to your bot to log expenses

💬 Option 2 — WhatsApp via Twilio (Paid service)

WhatsApp requires Twilio or similar — costs ~$15/month. Telegram is free and works exactly the same.
  1. Create account at twilio.com
  2. Enable WhatsApp Sandbox
  3. Copy Account SID + Auth Token
  4. Set webhook to your hosted CRM URL

💡 How the bot works: The bot runs on a free cloud server (Render.com or Railway.app — both free tier). It receives your WhatsApp/Telegram message, parses it, and writes the expense to your Firebase database (if Firebase sync is set up). Your CRM reads from the same database and shows the entry instantly.
